# Mosque Finance Management System

A transparent, digitalized, and user-friendly finance management web application designed for local mosques. This system helps the mosque committee track donations, manage expenses, and provide digital receipts to donors, ensuring 100% accountability.

## 🚀 Features (Upcoming)
- **Digital Donations:** Integration with local MFS (bKash, Nagad) via QR code.
- **Automated Receipts:** Instant digital receipts for donors.
- **Expense Tracking:** Complete log of utility, maintenance, and development expenses.
- **Transparent Dashboard:** Visual analytics (weekly, monthly, yearly) of funds.

## 🛠️ Tech Stack
- **Frontend:** Next.js / React (via Vercel)
- **Backend & Database:** Firebase (Firestore & Authentication)
- **AI Orchestration:** Google Antigravity 2.0
